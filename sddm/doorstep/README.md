# Doorstep (login screen)

*Coming home / waiting at the door.*

**Status:** planned. Nothing to install yet.

Qt 6 SDDM theme: the cat waiting at the door when you come home.

- Follows Tabby & Tweed colours, with a Sunbeam wallpaper as the background.
- Must work with SDDM on Wayland (your current setup) and keep the user list, keyboard layout, and power and virtual-keyboard buttons.
- Installs to `/usr/share/sddm/themes/doorstep` (needs sudo, so the owner runs it).
