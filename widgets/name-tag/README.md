# Name Tag (window title widget)

*A name badge / a collar tag.*

**Status:** planned. Nothing to install yet.

Plasma 6 widget that shows the active window's icon and title in the panel. It replaces the old *Window Title* widget, which no longer loads in Plasma 6 because it used a private module.

- Public APIs only (`org.kde.taskmanager`).
- Options: icon only, title only, or both; maximum width; and what to show on an empty desktop.
- Id: `com.github.techonerd.nametag`.
