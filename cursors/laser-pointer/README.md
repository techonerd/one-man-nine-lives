# Laser Pointer (cursors)

*The hand holding it / the cat chasing it.*

**Status:** planned. Nothing to install yet.

Cursor theme with a small laser-dot accent; the busy cursor is a chasing paw.

- Light and dark variants (cursors can't follow the colour scheme by themselves).
- Built from SVG sources into Xcursor and the newer SVG cursor format that KWin on Wayland supports.
- Installs to `~/.local/share/icons/laser-pointer`.
