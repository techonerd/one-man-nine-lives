# Sunbeam (wallpapers)

*Morning light / the warm spot on the floor.*

**Status:** planned. Nothing to install yet.

Original wallpapers: a sunbeam crossing a floor where a cat naps.

- A **day/night pair** in one Plasma 6 wallpaper package, so Plasma swaps it automatically with light/dark.
- Multiple resolutions including 16:10 (your Flow X16), plus a matching Doorstep background.
- Installs to `~/.local/share/wallpapers/sunbeam`.
