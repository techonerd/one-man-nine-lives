# Task: Night Shift (Plasma style + Konsole colours)

*Late-night work / a nocturnal hunter.* Read `AGENTS.md`, `tasks/README.md`, `plasma-style/night-shift/README.md`.

## Build
1. A Plasma 6 style (`Plasma/Theme` package) in `plasma-style/night-shift/night-shift/`: panel background, dialogs/popups, tooltips, widget backgrounds and buttons as SVGs whose colours use Plasma's stylesheet classes (`ColorScheme-Background`, `ColorScheme-Text`, `ColorScheme-Highlight`…), so **one style follows Tabby & Tweed Light and Dark automatically**. Rounded corners, soft shadow, thin accent hairline on the panel's top edge.
2. Konsole colour schemes `NightShiftLight.colorscheme` and `NightShiftDark.colorscheme` (+ a `Night Shift.profile`) derived from the palette, with WCAG ≥ 4.5:1 for normal text.
3. Everything generated by `plasma-style/night-shift/tools/generate.py`.

## Test (no install)
- Render key SVG elements on light and dark backgrounds into `preview.png`; render a 16-colour Konsole swatch for both schemes.
- Contrast check script output pasted in `REVIEW.md`.

## Deliver
`REVIEW.md` with: style → `~/.local/share/plasma/desktoptheme/night-shift` then `plasma-apply-desktoptheme night-shift` (undo: `plasma-apply-desktoptheme default`); Konsole files → `~/.local/share/konsole/`.
