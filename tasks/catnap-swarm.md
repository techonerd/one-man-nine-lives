# Swarm prompt: animated Catnap

**How to start**: open this repository as the Antigravity workspace, start a new conversation, type `/swarm`, then: *Run the swarm described in `tasks/catnap-swarm.md`.* Nothing in this file needs editing.

---

Build Phase 2 of `tasks/catnap.md` (animated Catnap) in this repository. The spec is that section; read it, `AGENTS.md` and `tasks/README.md` before splitting the work. Use the `plasma-polish` skill (`.agents/skills/plasma-polish`) for every QML and art decision.

**Rules for every worker** (copy these into each brief, since workers see only their brief):
- Read `AGENTS.md`, `tasks/README.md` and the "Phase 2: animated Catnap" section of `tasks/catnap.md` first.
- Never install, never use `sudo`, `kpackagetool6`, `plasma-apply-*`, `systemctl` or `kscreenlocker_greet`; never write outside the repository except `/tmp`. Never commit, push, stash or revert. Touch only the files you own.
- Colours only from `color-scheme/tabby-and-tweed/tools/generate.py`. Artwork drawn by code, never AI images.

**Split: three workers and one verifier.** Each file has exactly one owner:

| Worker | Owns | Doesn't touch |
|---|---|---|
| `art` | `look-and-feel/one-man-nine-lives/tools/generate_lockscreen_art.py`; everything it generates: `catnap/metadata.json`, `catnap/contents/screenshot.png`, `catnap/contents/images/*`, `catnap/contents/ui/parts.js`; the parts doc `look-and-feel/one-man-nine-lives/catnap-parts.md` | `catnap/contents/ui/main.qml`, tests, install scripts |

| `verifier` | nothing; reads, runs checks, reports | everything |

The coordinator (not a worker) updates `install.sh`, `uninstall.sh`, `look-and-feel/one-man-nine-lives/README.md` and a REVIEW section at the end, once everything is accepted.

**The contract between workers.** Post this to the board before starting anyone, so all three build against the same interface:
1. `generate_lockscreen_art.py` must **stop deleting the whole `catnap/` folder**. Today `main()` runs `shutil.rmtree(PKG)`, which would wipe `main.qml`. It may only rewrite the files `art` owns.
2. `art` writes these to `catnap/contents/images/`: `background.svg` and the parts `body.svg`, `head.svg`, `tail-base.svg`, `tail-mid.svg`, `tail-tip.svg`, all in the existing cat art units (the 256×140 cat drawn at `CAT_SCALE` 2.4, placed at `CAT_X, CAT_Y` on the 2560×1600 scene).
3. `art` also writes `catnap/contents/ui/parts.js` (`.pragma library`). For the scene it exports `sceneW: 2560, sceneH: 1600`. For each part it exports `{ x, y, w, h, pivotX, pivotY }` in scene pixels: `body` (pivot = the middle of the floor line), `head` (pivot = neck), and `tailBase`, `tailMid`, `tailTip` (pivot = where each joins the previous part). `main.qml` scales everything by `width / sceneW`.
4. `metadata.json` (written by the art script) gets `"KPackageStructure": "Plasma/Wallpaper"` and `"X-Plasma-API-Minimum-Version": "6.0"`, keeping `"Id": "com.github.techonerd.catnap"`.
5. `main.qml` exposes these for tests and previews:
   - `property real clockMs` (driven by the one Timer; settable);
   - `property bool still`;
   - `property int seed` (a deterministic random sequence when set);
   - `readonly property int tickInterval` (125 or 33);
   - `readonly property real breathScale`;
   - `readonly property real tailBaseAngle`, `tailMidAngle`, `tailTipAngle`;
   - `readonly property bool flicking`.
   It must work when loaded on its own, outside Plasma: tests load it with `Plasmoid` unavailable, so guard any Plasma-only access.

**Order.** `art` and `motion` start at once, in parallel: `motion` can use plain rectangles at the contract positions until the art lands. `tests` starts at once too, from the contract, and runs against the real files when they arrive. Each worker posts `[done]` with what it changed and the exact commands it ran and their output.

**The verifier** checks each `[done]` against the spec. It runs:
- `python3 -I claude/plasma-polish/skills/plasma-polish/scripts/plasmalint.py look-and-feel/one-man-nine-lives/catnap` (0 FLOOR required);
- `qmllint`;
- the art script twice (the output must be identical);
- `QT_QPA_PLATFORM=offscreen /usr/lib/qt6/bin/qmltestrunner -input look-and-feel/one-man-nine-lives/tools/tst_catnap.qml -import /usr/lib/x86_64-linux-gnu/qt6/qml`.

It also checks the motion numbers in the spec: breath 3.7–4.3 s; rise 2.5 %; flicks every 10–18 s lasting 2 s; tail angles 3/6/10° with 120 ms stagger; ticks of 125 ms when idle and 33 ms during a flick. And it checks the resource rules: one Timer, no `NumberAnimation`/`Behavior`/`AnimatedImage`/`Canvas`/`layer`/blur; `asynchronous` and `cache` on images; `sourceSize` set; background at a quarter of the screen size. It sends anything wrong back to its owner by name.

Done means all checks pass and the verifier accepts all three. Then the coordinator writes the README and REVIEW (including the owner's commands from the spec) and stops. The owner will then ask Claude Code to run `plasma-polish review tasks/catnap.md` before committing.
