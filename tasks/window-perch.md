# Task: Window Perch (window decoration)

*Windows on the screen / the favourite windowsill.* Read `AGENTS.md`, `tasks/README.md`, `window-decoration/window-perch/README.md`.

## Build
An **Aurorae SVG** window decoration in `window-decoration/window-perch/WindowPerch/` (`metadata.json` with `KPackageStructure: "KWin/Aurorae"` if supported by this Plasma version, plus `decoration.svg`, `close.svg`, `maximize.svg`, `restore.svg`, `minimize.svg`, `alldesktops.svg`, `keepabove.svg`, `keepbelow.svg`, `shade.svg`, `help.svg`, and `WindowPerchrc`).
- Generated by `window-decoration/window-perch/tools/generate.py` from the Tabby & Tweed palette.
- Title bar colours must come from the **active colour scheme**: use Aurorae's colour-scheme stylesheet classes (`ColorScheme-...`) so Light and Dark both work from one theme. If something can't follow the scheme, generate Light and Dark variants.
- Style: soft rounded top corners, a thin "perch ledge" line under the title bar in the accent colour, close button with tiny cat-ear corners. Button states: normal, hover, pressed, inactive.

## Test (no install)
- Render every SVG element to PNG and a mock title bar (active + inactive, Light + Dark) into `preview.png`.
- Verify element ids match what Aurorae expects (document the list you checked against in `REVIEW.md`).

## Deliver
`REVIEW.md` with: `mkdir -p ~/.local/share/aurorae/themes && cp -r window-decoration/window-perch/WindowPerch ~/.local/share/aurorae/themes/`, then System Settings → Window Decorations; undo by deleting that folder.
