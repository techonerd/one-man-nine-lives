# Task: Laser Pointer (cursors)

*The hand holding it / the cat chasing it.* Read `AGENTS.md`, `tasks/README.md`, `cursors/laser-pointer/README.md`.

## Build
- Cursor SVG sources generated by `cursors/laser-pointer/tools/generate.py`: a clean arrow with a tiny laser-dot at the tip; text beam, hand, resize arrows, move, not-allowed, crosshair, and a **busy** animation of a chasing paw (6–12 frames).
- Light (dark cursor on light outline) and Dark (light cursor with dark outline) variants: `laser-pointer` and `laser-pointer-dark`.
- Build both formats with **`kcursorgen`** (installed): the SVG cursor format KWin uses on Wayland and classic Xcursor for X11 apps, at sizes 24, 32, 48, 64. Include `index.theme` and the standard alias symlinks (left_ptr → default, etc.); document the alias list used.

## Test (no install)
- `preview.png` contact sheet of every cursor at 32 and 48 px on light and dark backgrounds.
- Confirm the hotspot of each cursor (list them in `REVIEW.md`).

## Deliver
`REVIEW.md` with: `cp -r` into `~/.local/share/icons/`, then System Settings → Cursors; undo by deleting the folder.
