# Window Perch (window decoration)

*Windows on the screen / the favourite windowsill.*

**Status:** planned. Nothing to install yet.

Aurorae (SVG) window decoration: title bars with a subtle perch ledge and cat-ear corner accents on the close button.

- Takes title-bar colours from the active scheme ([WM] section), so it follows light and dark.
- Installs to `~/.local/share/aurorae/themes/WindowPerch`.
