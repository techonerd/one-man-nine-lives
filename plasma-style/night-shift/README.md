# Night Shift (Plasma style)

*Late-night work / a nocturnal hunter.*

**Status:** planned. Nothing to install yet.

Panel, popup and widget backgrounds as SVGs that use Plasma's colour-scheme stylesheet classes, so one style follows both Tabby & Tweed Light and Dark automatically.

- Plasma 6 `Plasma/Theme` package; installs to `~/.local/share/plasma/desktoptheme/night-shift`.
- Also provides the matching Konsole profile and colours, generated from the Tabby & Tweed palette.
