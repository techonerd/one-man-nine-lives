# Casper Parts Art Contract (Doorstep SDDM Theme)

This document specifies the vector art contract for the modular Casper illustrations used by `CasperGrabber.qml` in `sddm/doorstep/doorstep/casper/`.

All parts are authored in Adobe Illustrator and exported as clean SVG files into two directories:
- `sddm/doorstep/doorstep/casper/dark/` (for Dark mode)
- `sddm/doorstep/doorstep/casper/light/` (for Light mode)

The QML component loads all assets strictly from `casper/<variant>/<name>.svg`, ensuring that exporting final artwork replaces the placeholders without any QML code changes.

## Palette Rules
- **Casper's Coat**: Off-white `#F5F5F5` (MONO coat; never pure `#FFFFFF`).
- **Dark Mode**: Background `#141414`, Casper has no stroke (`outline="none"`), subtle drop shadow `rgba(0, 0, 0, 0.45)`, detail color `#222222`.
- **Light Mode**: Background `#F7F7F7`, Casper has near-black outline `#121212` (`stroke-width="2.5"` / >= 3:1 WCAG contrast), soft shadow `rgba(0, 0, 0, 0.15)`, detail color `#121212`.
- **Inner Ear & Paw Beans**: Rose tint (`rgba(0, 0, 0, 0.08)` dark, `rgba(0, 0, 0, 0.10)` light or `#F0807A`).
- **Cursor Glyph**: Captured arrow in `paw-holding-cursor.svg` uses `#E6E6E6` fill / `#141414` stroke in dark, `#1C1C1C` fill / `#F7F7F7` stroke in light.

## Placeholder Generation
Temporary placeholders adhering to this contract are generated by `sddm/doorstep/tools/generate.py` using helper routines derived from `art/casper.py` (`sit`, `paw`, `tail` poses).
When final SVGs are ready from Illustrator, save them over `sddm/doorstep/doorstep/casper/<variant>/<name>.svg` to update the visual assets with zero QML modifications.
