# Working on One Man Nine Lives (for AI agents and contributors)

A KDE Plasma 6 suite by one man and his cat, Casper. Every component name balances a human side and a cat side (see README.md).

## Hard rules
- **Never run commands that change the system**: no `sudo`, no package installs, no `systemctl` enable/start/stop/disable, no `kpackagetool6` install/remove, no writing outside this repository. Write the command into your answer and let the owner run it.
- **Never commit or push.** The owner reviews and commits.
- **Whiskers stays read-only**: checks may read and measure, but never fix, restart or delete anything. Fix commands are only *shown*.
- **Plasma 6 only**: `metadata.json`, Qt 6 QML imports, no private `org.kde.plasma.private.*` modules. Config pages declare a `cfg_<key>` and a `cfg_<key>Default` for every key in `main.xml`.
- **Follow the system theme**: use `Kirigami.Theme` colours and themed icon names. Never hard-code light or dark colours in widget UI. Monochrome icons use the `ColorScheme-Text` stylesheet class.
- **Original work only**: no code or artwork copied from other themes or projects. Icons are generated by `icons/thumbs-and-paws/tools/generate.py`.
- **One palette**: every colour comes from `color-scheme/tabby-and-tweed/tools/generate.py`; don't invent new hex values elsewhere.
- **Versions**: every component is 0.1.0 until the whole suite is done and tested; then all move to 1.0.0 together. Tags are `<component>-v<version>`. Ids are `com.github.techonerd.<name>`.
- **Privacy**: no personal data in code, URLs or requests. The only network call allowed is the anonymous GitHub release lookup in `whiskers/checks.d/releases`.

## Layout
| Path | What |
|---|---|
| `splash/morning-stretch/` | Splash screen (Plasma/LookAndFeel package) |
| `whiskers/bin/whiskers` | CLI core: config, plugin runner, live watch, notifications |
| `whiskers/checks.d/` | Check plugins (`describe` / `run`, JSON lines; see `whiskers/lib/common.sh`) |
| `whiskers/lib/watch-filter.jq` | Journal → event rules for the live watch |
| `whiskers/lib/names.tsv` | Process → friendly name → what it means for the user |
| `whiskers/widget/` | Plasma 6 widget (popup and settings page built from `whiskers plugins --json`) |
| `icons/thumbs-and-paws/` | Icon theme + generator |
| `color-scheme/tabby-and-tweed/` | Light + dark colour schemes; `tools/generate.py` is the single source of the suite palette and enforces WCAG contrast |
| `look-and-feel/one-man-nine-lives/` | Global themes Light + Dark, generated by `tools/generate.py` (defaults + previews); never add a layout script or wallpaper |
| `sddm/`, `plasma-style/`, `window-decoration/`, `cursors/`, `wallpapers/`, `widgets/`, `sounds/` | Planned components; each folder's README is its spec |

## Writing style for Whiskers messages
Plain words for a non-expert: *what happened*, *what it means for you*, *what to do*. No jargon in titles. Exact commands go in `fix`, raw log lines in `detail`.

## UI/UX work: the plasma-polish skill
Claude Code and Antigravity share one skill, `claude/plasma-polish/skills/plasma-polish/` (linked from `.claude/skills/` and `.agents/skills/`). Use it for any review or change to how something looks or behaves. The usual split: one agent does the heavy `polish`/`new` work from a `tasks/` brief; the other runs `review <task>` on the diff before the owner commits. Its checkers are read-only:
```bash
python3 -I claude/plasma-polish/skills/plasma-polish/scripts/plasmalint.py <folder>
python3 -I claude/plasma-polish/skills/plasma-polish/scripts/contrast.py [scheme.colors ...]
```

## How to test without installing
```bash
export WHISKERS_STATE_DIR=/tmp/wk/state WHISKERS_CONFIG_DIR=/tmp/wk/conf WHISKERS_UNIT_DIR=/tmp/wk/units
whiskers/bin/whiskers status
whiskers/bin/whiskers plugins --json | jq .
/usr/lib/qt6/bin/qmllint -I /usr/lib/x86_64-linux-gnu/qt6/qml whiskers/widget/contents/ui/*.qml   # "unqualified i18n/root" warnings are expected
python3 -I icons/thumbs-and-paws/tools/generate.py && icons/thumbs-and-paws/tools/preview.sh
python3 -I color-scheme/tabby-and-tweed/tools/generate.py && python3 -I color-scheme/tabby-and-tweed/tools/preview.py
QT_QPA_PLATFORM=offscreen /usr/lib/qt6/bin/qmltestrunner -input sddm/doorstep/tools/tst_casper_grabber.qml -import /usr/lib/x86_64-linux-gnu/qt6/qml   # Doorstep cat follows and grabs the pointer
./build.sh
```
